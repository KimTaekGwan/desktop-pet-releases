0.3.0 2026-11-03

  • 창 테두리·화면 가장자리에 매달리기: 끌어다 놓으면 고무줄처럼 붙고, 창을 따라가고, 가려지면 떨어졌다가 돌아오면 다시 붙어요. 우클릭 "가장자리에 걸기 / 떼어내기".
  • 마우스를 0.5초 올리면 손 흔들기, 더블클릭하면 크게 인사. 커서 피하기 / 따라오기 / 무시 모드, 제자리 고정.
  • 에이전트 상태에 실패(✕)·검토 대기(👀) 추가. 작업 중 상태가 N분 소식 없으면 자동 종료(설정). pure-pet 호환 HTTP 작업 서버(POST /task/start|complete|fail|review, 기본 꺼짐).
  • 전역 단축키 5종(설정에서 녹음): Mini ⌃⌥P · 펫 보이기/숨기기 ⌃⌥H · 조용히 모드 ⌃⌥Q · 펫에게 한마디 ⌃⌥I · 활동 기록 ⌃⌥E.
  • 말풍선 테마 6종, 액세서리(고깔모자·화관·안경·목도리 + 내 PNG), pure-pet 캐릭터 가져오기/내보내기.
  • 펫끼리 공 던지기(맞으면 기절), 펫이 골라 주기(룰렛·제비뽑기).
  • 영어 UI(시스템 언어가 영어일 때), 하루 한 번 새 버전 확인, 설정 → "문제 보고…".
