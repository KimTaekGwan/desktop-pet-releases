  • 하루 루틴: 자리를 비우면(권한 없이 마지막 입력 시각만 봄) 월페이퍼 모드의 펫이 자기 구역을 돌아다니고, 돌아오면 "왔어?", 아침 기지개·점심·밤 하품, 90분 연속 입력 "쉬었다 해". 하루 6회·시간당 1회 상한, 조용히 모드면 0회
  • 시선·몸짓: 커서를 눈으로 따라봄, 머리 쓰다듬기 / 배 간지럼, 길게 눌러 안기, 눈싸움
  • 집: 바탕화면 소품(밥그릇=배고픔, 쿠션=잠자리, 화분=나이, 창문·전등=낮밤, 액자, 간식) — 보기 → "집 소품 한 벌 놓기", 편집기에서 소품·펫 구역. 밥그릇·간식은 hover 뒤 눌러서 먹이기
  • 떨어뜨리기: 펫 위에 사진 → 액자에 걸림, 텍스트 → 📝, 파일 → 이름 묻기
  • 창 틈 엿보기: 월페이퍼 모드에서 창에 가려지면 30초 뒤 창 틈으로 고개를 내밀고(확인 요청이면 바로), 창이 비키면 돌아옴. 발자국, 밤의 전등 불빛, 시간대 틴트
  • 시간·날씨: 시간대 바탕화면 4장(Codex) 자동 교체, Open-Meteo 날씨(도시 이름) → 비 우산·눈 눈사람/눈 내림·더위 선풍기
  • 기념일·일기: 생일·100일·계절 액세서리와 한마디, 아침에 밤사이 일기 한 줄
  • 대화: 펫에게 한마디에 규칙 응답("잘 자"→잠, "배고파?"→밥…), 메모는 memory.json에 기억해 아침에 회상, 선택적으로 Codex가 캐릭터로 한 줄 답
  • 지금 장면 저장: 바탕화면+소품+펫을 PNG로(사진 폴더 + 클립보드, 캡처 권한 불필요), desktoppet://snapshot
  • 자유 시간에 펫 둘이 공놀이·자는 친구 챙기기
  • 안정성: URL로 펫을 보내도 위젯 파일까지 정리, 매달린 채로는 거대화·기절 안 함, 쿠션 가서 자기가 다른 걸음에 묻혀 사라지지 않음, 종료 때 타이머·서버 정리, 캐릭터 zip·갤러리 압축 풀기를 백그라운드로
  • 펫이 둘일 때 Mini 패널이 겹치지 않게 옆으로 비킴, 알림 문장 영어 번역
  • 이미지 생성(캐릭터·바탕화면)에 10분 시간 제한 — Codex가 멈춰도 펫이 계속 일하는 척하지 않음
  • 월페이퍼 모드에서 밥그릇·쿠션까지 걷다가 중간에 멈추거나 목표를 다시 잡던 문제
  • 영어 UI: 메뉴의 "놀이"가 "놀아주기"와 같은 Play로 겹치던 것(→ Games), 수치 줄·캐릭터 만들기 대화상자·업데이트 확인 문장 번역
  • 내부 정리: 명령 경로 하나(URL·HTTP·위젯·메뉴), 설정 변경 자동 반영, 앱 코드를 기능별로 나눔, 테스트 112 → 170개

0.3.0 2026-11-03

  • 창 테두리·화면 가장자리에 매달리기: 끌어다 놓으면 고무줄처럼 붙고, 창을 따라가고, 가려지면 떨어졌다가 돌아오면 다시 붙어요. 우클릭 "가장자리에 걸기 / 떼어내기".
  • 마우스를 0.5초 올리면 손 흔들기, 더블클릭하면 크게 인사. 커서 피하기 / 따라오기 / 무시 모드, 제자리 고정.
  • 에이전트 상태에 실패(✕)·검토 대기(👀) 추가. 작업 중 상태가 N분 소식 없으면 자동 종료(설정). pure-pet 호환 HTTP 작업 서버(POST /task/start|complete|fail|review, 기본 꺼짐).
  • 전역 단축키 5종(설정에서 녹음): Mini ⌃⌥P · 펫 보이기/숨기기 ⌃⌥H · 조용히 모드 ⌃⌥Q · 펫에게 한마디 ⌃⌥I · 활동 기록 ⌃⌥E.
  • 말풍선 테마 6종, 액세서리(고깔모자·화관·안경·목도리 + 내 PNG), pure-pet 캐릭터 가져오기/내보내기.
  • 펫끼리 공 던지기(맞으면 기절), 펫이 골라 주기(룰렛·제비뽑기).
  • 영어 UI(시스템 언어가 영어일 때), 하루 한 번 새 버전 확인, 설정 → "문제 보고…".
