Never in your way

살아 있는 상태

Actually alive

배고픔·행복·에너지, 알 → 아기 → 성체. 꺼 둔 시간도 반영돼요. 스스로 돌아다니고, 졸리면 자고, 높은 데서 낮잠을 자요.

Hunger, happiness, energy; egg → baby → adult. Time passes while the app is closed. It wanders, naps when tired, sleeps on high ledges.

창에 걸어 두기

Hang it on a window

창 옆·아래 테두리나 화면 가장자리에 끌어다 놓으면 고무줄처럼 붙어요. 창을 옮기면 따라오고, 가려지면 떨어졌다가 돌아오면 다시 붙어요.

Drop it near a window edge or the screen edge and it snaps on like a rubber band. Follows the window, falls when covered, climbs back when it returns.

설치

Install

  1. Releases에서 zip을 받아 풀고 DesktopPet.app을 응용 프로그램 폴더에 옮깁니다.
  2. Grab the zip from Releases, unzip, move DesktopPet.app to Applications.
  3. 그냥 더블클릭하면 열려요. Developer ID 서명 + Apple 공증을 마쳐서 Gatekeeper 경고가 없어요.
  4. Just double-click it. Signed with a Developer ID and notarized by Apple — no Gatekeeper warning.

앱은 하루 한 번 이 저장소의 latest.json만 읽고, 그 외 어떤 것도 보내지 않아요.

The app reads this repo's latest.json once a day and sends nothing else.

에이전트 연동 한 줄

One-line agent integration

# URL 스킴 / URL scheme
open -g "desktoppet://agent/working?agent=Claude%20Code&label=빌드%20중"
open -g "desktoppet://agent/done"

# petctl (설정 → 연동 → petctl 설치)
petctl agent attention "Claude Code" "확인해 주세요"

# pure-pet 호환 HTTP (설정 → 연동에서 켜기)
curl -X POST localhost:9090/task/start -d '{"name":"테스트","agent":"Codex"}'   # {"task_id":1}
curl -X POST localhost:9090/task/complete -d '{"task_id":1}'

FAQ

펫이 다른 창 뒤에 숨어요The pet hides behind windows

설정 → 펫 → 표시 위치가 "앞"인지 확인하세요. "뒤"는 일부러 창 아래, "월페이퍼"는 바탕화면 그림처럼 두는 모드예요.

Settings → Pet → Placement should be "Front". "Behind" and "Wallpaper" deliberately keep it under windows.

월페이퍼 모드에서 못 잡아요Can't grab it in wallpaper mode

마우스를 펫 위에 0.3초 올려 두면 살짝 커지면서 잡을 수 있게 올라와요. Finder 아이콘 층 아래에 있어서 그래요.

Hover for 0.3 s — it pops up above the Finder icon layer so you can grab it.

알림이 안 와요No notifications

설정 → 일반 → "알림 권한 요청" 버튼으로 시스템 설정에서 허용해 주세요. 조용히 모드(기본 ⌃⌥Q)가 켜져 있으면 전부 멈춰요.

Settings → General → request permission, then allow it in System Settings. Quiet mode (⌃⌥Q by default) silences everything.

위젯이 비어 있어요The widget is blank

macOS 14 이상에서, 위젯을 지웠다가 다시 추가한 뒤 "위젯 편집"에서 펫을 고르세요. 앱이 한 번은 실행돼 있어야 해요.

Needs macOS 14+. Remove and re-add the widget, then pick a pet in "Edit Widget". The app must have run at least once.

무엇을 수집하나요?What does it collect?

아무것도요. 화면 내용·키 입력·파일을 읽지 않고, 네트워크는 업데이트 확인(latest.json)과 사용자가 직접 켠 AI 캐릭터 생성(Codex/OpenAI)뿐이에요.

Nothing. No screen contents, keystrokes or files. Network use is the update check (latest.json) and AI character generation you start yourself (Codex/OpenAI).
